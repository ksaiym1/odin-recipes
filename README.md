# odin-recipes

Project Description

The project is about creating a webpage called "Recipes" using only HTML. The page contains links to a total of three cooking recipes.
In each individual recipe pages, there is a image of the completed dish. Under the image, there is a list of ingredients and step by step guide for making the dish.

The skills I needed to demonstrate are -
1. Create and work with different HTML files.
2. Use basic elements and tags.
3. Automate HTML Boilerplate.
4. Create ordered and unordered lists.
5. Add links and images to the HTML files.
